# Assets, kilder og licenser

Første version bruger **ingen eksterne filer**. Alt er lavet i kode:

| Hvad | Hvordan |
|---|---|
| Træer, sten, buske, hule, dyr, jæger, pile, loot | Simple lavpoly-modeller bygget af Three.js-geometri (`src/world`, `src/animals/models.ts`, `src/player/Player.ts`) |
| Terræn, himmel, stjerner | Genereret (`src/world/World.ts`, `src/world/Sky.ts`) |
| Lyd | Syntetiseret med WebAudio (`src/audio/Sound.ts`) |
| Skrifttype | Systemets Georgia/serif |

Three.js er MIT-licenseret.
